Install in one command

Copy one line into your computer's terminal and the installer does the rest. If Tourbine is already installed, it keeps your existing tours and photos.

Run in your terminal

$ curl -fsSL https://get.tourbine.efenow.xyz/install.sh | bash

Run in PowerShell as your user

PS> irm https://get.tourbine.efenow.xyz/install.ps1 | iex

The installer then asks how you want to run it:

Docker Always-on server

The best choice for a computer that stays on and serves your tours. Needs Docker installed first.

npm Trying it out

Good for trying Tourbine on your own computer. Needs Node.js and a few developer tools installed first.

Prefer to install manually? Step-by-step commands for IT staff

From source with npm

Needs Node.js LTS and npm. The SQLite driver is a native addon, so building needs python3, make, and g++.

  1. Clone the repository 
    git clone https://github.com/efenow/tourbine.git
  2. Enter the project directory 
    cd tourbine
  3. Install dependencies and start 
    npm install
npm start
  4. Development (auto-restart on file change) 
    npm run dev

With Docker Compose

Run from the cloned repository. Compose sets NODE_ENV=production and PORT=3000.

  1. Build and start in the background 
    docker compose up -d --build
  2. View logs 
    docker compose logs -f
  3. Stop 
    docker compose down
  4. Update to a newer commit 
    git pull
docker compose up -d --build

The database and uploads live in the named volumes tourbine_data (/app/data) and tourbine_uploads (/app/public/uploads), so they survive restarts and rebuilds.

Questions before you install

Is Tourbine really free?

Yes. There are no paid plans or subscriptions. You run Tourbine on your own computer or server, and your tours and photos stay there.

What can I make with it?

Virtual tours made of 360° photos, regular photos and videos, joined by clickable links between rooms, with info points along the way. Share a tour by link or add it to your own website.

Which install option should I pick?

Pick Docker for a computer that stays on and serves your tours, such as one your IT team looks after. Pick npm to try Tourbine on your own computer first.

How do I put my tours on the internet?

Use Cloudflare Tunnel, which puts your tours online without changing your router settings. The dashboard has a settings page that helps you set it up.

I lost the admin password. What now?

Whoever installed Tourbine can run the reset tool, node reset-password.js. It works even while Tourbine is stopped.

Where are my tours and photos stored?

In the Tourbine folder on your computer or server. Tours are saved in data/tourbine.db and photos in public/uploads.
