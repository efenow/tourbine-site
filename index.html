Self-hosted 360° virtual tours

Free, open source 360° virtual tour software

Tourbine is self-hosted virtual tour software for creating, managing, and sharing interactive tours from your own server. Add rooms, connect them with hotspots, and publish when ready.

01

Build

Rooms take any of six media types:

  • 360° image
  • Still image
  • Local video
  • YouTube
  • Vimeo
  • iframe embed
  • Link rooms with labeled hotspots, or point hotspots to external URLs
  • Place info points on 360° and still images
  • Click in the panorama to set the initial view and hotspot positions
  • Blur or mosaic sensitive areas before upload
  • Reorder rooms, pick a default room, set auto-rotate and field of view
02

Publish

Share a link, embed the tour, or read it as JSON.

  • Public tour list and full-screen tour pages
  • Embed mode with a copyable <iframe> snippet
  • Optional cover image per tour
  • Read-only JSON API for headless use
  • Cloudflare Tunnel settings page for public access without port-forwarding

Run

Manage people, numbers, and backups.

  • Users with System admin, Admin, and User roles
  • Views for all time, 24 hours, and 7 days, per tour
  • Export and import whole tours as ZIP files
  • Duplicate a tour's structure in one click
  • Reset a lost password from the command line

Secure by default

  • bcrypt password hashes, cost factor 12
  • CSRF token checks on every write request
  • 10 login attempts per 15 minutes per IP
  • httpOnly, sameSite: 'strict' session cookies, secure in production

Install in one command

Tourbine runs as one Node.js process on port 3000. The installer handles the setup and keeps your existing Docker volumes with the database and uploads.

Run in your terminal

$ curl -fsSL https://get.tourbine.efenow.xyz/install.sh | bash

Run in PowerShell as your user

PS> irm https://get.tourbine.efenow.xyz/install.ps1 | iex

The installer then asks you to pick a method:

Docker Servers & production

Handles native dependencies and keeps the app isolated. Recommended on Windows production systems; needs Docker Desktop or another Docker-compatible engine.

npm Local development

Useful on macOS, Linux development machines, and WSL. Needs Node.js, npm, and build tools for better-sqlite3.

Prefer to install manually? npm, Docker, and environment variables

From source with npm

Needs Node.js LTS and npm. The SQLite driver is a native addon, so building needs python3, make, and g++.

  1. Clone the repository 
    git clone https://github.com/efenow/tourbine.git
  2. Enter the project directory 
    cd tourbine
  3. Install dependencies and start 
    npm install
npm start
  4. Development (auto-restart on file change) 
    npm run dev

With Docker Compose

Run from the cloned repository. Compose sets NODE_ENV=production and PORT=3000.

  1. Build and start in the background 
    docker compose up -d --build
  2. View logs 
    docker compose logs -f
  3. Stop 
    docker compose down
  4. Update to a newer commit 
    git pull
docker compose up -d --build

The database and uploads live in the named volumes tourbine_data (/app/data) and tourbine_uploads (/app/public/uploads), so they survive restarts and rebuilds.

Virtual tour software FAQ

Why use Tourbine?

Is Tourbine free virtual tour software?

Yes. Tourbine is free and licensed under GPL-3.0. Run it on your own hardware without a hosted subscription.

Is Tourbine open source and self-hosted?

Yes. Tourbine is open source self-hosted software. You keep your database and uploaded media on your own server.

What can Tourbine create?

Create interactive 360° virtual tours with panoramic images, video, hotspots, information points, embeds, and shareable links.

Should I choose Docker or npm?

Docker is recommended for servers and production. It handles native dependencies and keeps the app isolated. npm is recommended for local development and needs Node.js, npm, and native build tools.

How do I make my tours public on the internet?

Use Cloudflare Tunnel for public access without port-forwarding. The repository includes an example tunnel config, and the dashboard has a Cloudflared settings page that shows a generated config preview.

I lost the admin password. What now?

Run node reset-password.js. It opens the SQLite database directly, so it works even when the server is not running.

Where is my data stored?

The SQLite database is at data/tourbine.db and uploads go to public/uploads. Change them with DB_PATH and UPLOADS_DIR.
