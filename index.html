Install Tourbine

Tourbine runs on port 3000 and supports Cloudflare Tunnel for easy public access without port-forwarding.

  1. Clone the repository 
    git clone https://github.com/efenow/tourbine.git
  2. Enter the project directory 
    cd tourbine
  3. Install dependencies 
    npm install
  4. Update dependencies 
    npm update
  5. Start the server 
    npm start

Open http://localhost:3000 in your browser once the server starts.

Requirement: Docker with Docker Compose

Quickstart — build and start in the background

docker compose up -d --build

View logs

docker compose logs -f

Stop

docker compose down

Upgrade

docker compose pull
docker compose up -d --build

Data (SQLite database and uploaded images) is automatically persisted in Docker named volumes tourbine_data and tourbine_uploads, surviving container restarts and upgrades.
