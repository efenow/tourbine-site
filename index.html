Self-hosted 360° virtual tours

Publish interactive tours without giving up your data.

Tourbine is an open source web app for creating, managing, and sharing virtual tours from your own server. Add rooms, connect them with hotspots, and publish when ready.

Built for real tour projects

Everything needed to build a tour

Create rooms

Use 360° images, stills, local video, YouTube, Vimeo, or iframe embeds.

Connect the experience

Link rooms with labeled hotspots so visitors can move naturally through a space.

Add useful context

Place info points on images and link visitors to external pages when needed.

Edit visually

Choose initial views and hotspot positions by clicking directly on the image.

Protect your media

Blur or mosaic sensitive areas before upload with the built-in image privacy editor.

Share and manage

Embed tours, export and import projects, track visits, and manage multiple users.

Tours can be embedded in other sites. A read-only JSON API is available for headless use.

Ready to run locally

Install in a few commands

Tourbine runs as one Node.js process on port 3000. Choose npm for a direct install, or Docker for an isolated setup. It supports Cloudflare Tunnel for public access without port-forwarding.

Linux quick install: run this command in your terminal.
curl -fsSL https://get.tourbine.efenow.xyz/install.sh | bash
PowerShell quick install: run PowerShell as your user.
irm https://get.tourbine.efenow.xyz/install.ps1 | iex
Requirement: Node.js LTS and npm. The SQLite driver is a native addon, so installing from source needs build tools (python3, make, g++); the Docker image installs them for you.
  1. Clone the repository 
    git clone https://github.com/efenow/tourbine.git
  2. Enter the project directory 
    cd tourbine
  3. Install dependencies 
    npm install
  4. Start the server 
    npm start

Open http://localhost:3000. On first run, /dashboard redirects to /dashboard/setup. Create the system admin account there: username at least 3 characters, password at least 8 characters.

Development (auto-restart on file change)

npm run dev

Environment variables: PORT (default 3000), DB_PATH (default data/tourbine.db), and NODE_ENV=production to turn on secure session cookies.

Requirement: Docker with Docker Compose

Quickstart — build and start in the background

docker compose up -d --build

View logs

docker compose logs -f

Stop

docker compose down

Update to a newer commit

git pull
docker compose up -d --build

The database and uploads are persisted in the named volumes tourbine_data (/app/data) and tourbine_uploads (/app/public/uploads), so they survive container restarts and rebuilds. Compose sets NODE_ENV=production and PORT=3000. For a public hostname, follow the Cloudflare Tunnel section in the repository README.
